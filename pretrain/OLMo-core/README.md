# OLMo-core

A copy of [OLMo-core](https://github.com/allenai/OLMo-core) (Apache-2.0, see `LICENSE`) with the
methods of the Depth Memory paper added: LDM (`src/olmo_core/nn/ldm/`), mHC
(`src/olmo_core/nn/hyper_connections.py`, `src/olmo_core/nn/mhc_ops.py`,
`src/olmo_core/kernels/tile_kernels/`) and AttnRes (`src/olmo_core/kernels/attnres.py`). It is
installed by `uv sync` at the repository root.
